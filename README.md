# Bilgisayar Oyunlarında Yapay Zeka — İnteraktif Araçlar

Hacettepe Üniversitesi, Bilgisayar Animasyonu ve Oyun Teknolojileri yüksek lisans programı kapsamında verilen **Bilgisayar Oyunlarında Yapay Zeka** dersi için hazırlanmış, tek dosyalık (HTML+CSS+JS) etkileşimli gösterim ve laboratuvar araçları.

## Canlı erişim

Tüm araçlar GitHub Pages üzerinden, kurulum gerektirmeden doğrudan tarayıcıda çalışır:

**https://guercay.github.io/bca503-oyun-ai-araclari/**

(Bu repoyu GitHub'a yükleyip Pages'i etkinleştirdikten sonra gerçek linki bu satırın yerine yazabilirsiniz.)

- **Öğrenciler için:** `index.html` sayfasındaki listeden ilgili konuya tıklamanız yeterli; her araç bağımsız çalışır.
